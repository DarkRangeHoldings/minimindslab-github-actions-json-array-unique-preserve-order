# JSON Array Unique

Deduplicate a JSON array while preserving the first occurrence order for deterministic workflow outputs.

Generated by MiniMindsLab 02.13 GitHub Action Factory.

## Usage

```yaml
- uses: ./path-to-action
  id: miniminds
  with:
    payload: '{"values":["b","a","b",1,1,true,true]}'
- run: echo '${{ steps.miniminds.outputs.result }}'
```

Runtime: Node 24. No external dependencies. No network access.
